# 🚀 teams-xscripts

(c) 2026 Josh Davis | [vinas1.github.io](https://vinas1.github.io)

Saves Chromium-based transcripts for use with Microsoft Teams (web version).

---

## 🛠️ Usage

Most of the time, this code will need to be copy-pasted into the console window of your favorite Chromium-based web browser.

### 📋 Steps to use:

1.  **Load Microsoft Teams** as a web app (recommended) or as a normal web page.
2.  **Copy** the `xscript` JS code.
3.  **Open** Developer Tools (`F12` or `Ctrl+Shift+I`).
4.  **Click** the **Console** tab.
5.  **Paste** the contents of the `xscript` JS code and press **ENTER**.
6.  **Keep** the console visible and join your Microsoft Teams Meeting. Observe that transcripts are visible as people begin to speak.
7.  **At the end of the meeting**, disconnect like normal, but ensure the Teams window remains **OPEN**.
8.  **In the Console**, type `getTXT()` and press **ENTER**. The file should download automatically.
9.  **If the file does not download** to your default destination, check the console for errors.
10. **On error**, follow the directions in the console to manually load the URI and save the file.
