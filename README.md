# teams-xscripts
(c) 2025 Josh Davis https://vinas1.github.io 
Saves chromium based transcripts for use with Microsoft Teams (web version).

USAGE: Most of the time this code will need to be copy/pasted into the console window of your favorite chromium web browser.

Steps:
1. Load Microsoft Teams as a web app (recommended) or as a normal web page.
2. Copy the xscript js code
3. Open Developer Tools
4. Click the Console Tab
5. Paste the contents of the xscript js code and press ENTER
6. Keep the console visible and join your Microsoft Teams Meeting - observe the transcripts are visible as people begin to speak.
7. At the end of the meeting, disconnect like normal but be sure to keep the Teams Window OPEN
8. In the Console type getTXT(); and press return, the file should download automatically.
9. If the file does not download to your default download destination, view the console for errors.
10. On error, follow the directions in the console to manually load the URI and save the file for future use.
